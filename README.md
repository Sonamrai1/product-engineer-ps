## My submission (Sonamrai)

I built and submitted solutions for **all four problems** rather than one.

**Why:** I wanted to demonstrate range across different engineering domains —
mobile offline-first patterns, backend reliability, real-time systems, and
agent orchestration — rather than depth on just one.

*Note: this repository's `problems/` folder was updated to a new 5-problem
set after I forked it. My four solutions below correspond to the earlier
version of the challenge (Offline Mobile Queue, Webhook Retry Engine,
Reconnecting Real-Time Feed, Observable Agent Loop) that was live at the
time I started.*
